## 2. 환경 구성 방식

- Python 가상환경(venv)을 `--system-site-packages` 로 만들어, 서버에 이미 있는 Python·torch 를 그대로 쓰고 학습 패키지만 가상환경에 설치
- Anaconda 는 쓰지 않음: Anaconda 로 새 환경을 만들면 B200 용 torch(CUDA 12.8 이상 빌드)를 따로 받아 다시 설치해야 함. 서버 torch 는 이미 B200 을 지원함 (확인)
- 서버 torch 는 바꾸지 않음: torch 를 쓰는 패키지는 `--no-deps` 로 설치해 pip 가 torch 를 다른 버전으로 바꾸지 못하게 함
- Python 버전을 팀 시험 환경(3.10)에 맞추지 않음: 서버는 3.12.3 (확인), 학습 코드 경로에 Python 3.12 에서 없어진 모듈을 쓰는 곳이 없음 (코드 확인)
- 서버 Python 은 Ubuntu 기본 Python(`/usr/bin/python3`)이라 가상환경 없이 `pip install` 하면 Ubuntu 보호 규칙(`externally-managed-environment`)에 걸릴 수 있음 (추정) → 가상환경 안에서 설치

**서버 폴더**

```
/NHNHOME/workspace/
  AnyDoor/                          AnyDoor 공식 코드 (커밋 44ca2b2)
    checkpoints/epoch=1-step=8687.ckpt     시작 가중치 (AnyDoor 공식)
    checkpoints/dinov2_vitg14_pretrain.pth
    data/zalando-hd-resized/train/   VITON-HD 6개 폴더
    data/zalando-hd-resized/test/    VITON-HD 6개 폴더
  CGI_MOA/                          팀 저장소 (브랜치 cej-retrain)
  anydoor/                          가상환경 (소문자, 코드 폴더 AnyDoor 와 다른 폴더)
  env_anydoor.sh                    새 터미널마다 불러오는 설정 파일
  retrain_run/                      학습 결과 폴더
```

- 가상환경과 데이터는 `/NHNHOME/workspace` 에 둠. 홈 폴더(`~`)가 컨테이너를 다시 시작한 뒤에도 남는지는 미확인

| 패키지 | 이유 |
