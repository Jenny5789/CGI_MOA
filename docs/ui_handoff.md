# 화면 담당 전달 사항

- 서버(AI 기능·서버 담당)가 준비한 것 중 **화면에 붙이거나 확인할 것** 모음
- 전달한 날짜별로 묶음, 처리하면 `[ ]` → `[x]`
- 서버 실행·화면 연결 방법: [../README.md](../README.md) "화면과 서버 함께 쓰기"

  - 설정 전이면 로그인 시 "로그인 서버(DB)에 연결되어 있지 않습니다." (추출·합성은 정상)
- [ ] **화면 파일 수정 알림** (서버 연결 때 손댄 곳, 확인 부탁)

  - `src/pages/Studio.jsx`: 사진 올리기·추출·합성·저장을 실제 서버로 연결
  - 같은 파일, "합성 중" 문구 뒤에 상황에 따라 붙는 글자 추가
    - `(NN%)`: 합성이 진행 중일 때 (시작 직후 0%일 때는 숫자 없이 "합성 중"만)
    - `(대기 N번째)`: **앞에 다른 사람의 합성이 돌고 있을 때만** (합성은 한 번에 하나씩) → 혼자 시험하면 보이지 않음

  - `POST /api/auth/register` `{ username, password, name, email }` → 로그인과 같은 응답 (가입 후 바로 로그인 상태)
