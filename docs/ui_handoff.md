  | 설정 | 화면이 묻는 곳 | 로그인 | 필요한 것 |
  |---|---|---|---|
  | `mock` (기본) | 화면 안의 가짜 서버(`src/api/mock.js`) | `test` / `test` | 없음. 화면만 볼 때 |
  | `mixed` | 실제 서버(`backend/`) | `test` / **`test1234`** | 서버 실행 + **각자 컴퓨터에 MySQL 설정** ([database.md](database.md)) |

  - `mixed`에서는 실제 서버가 MySQL에 저장된 회원으로 아이디·비밀번호를 확인함
  - MySQL 설정 전이면: 로그인 때 "로그인 서버(DB)에 연결되어 있지 않습니다." 알림. 이때도 사진 올리기·추출·합성은 동작
  - 비밀번호가 `test1234`인 이유: 팀 비밀번호 규칙(8자 이상, 숫자 포함)을 실제 서버가 지킴
