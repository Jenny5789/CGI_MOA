## 실행 위치와 규칙

| 표기 | 위치 |
|---|---|
| [PC] | 학습용 컴퓨터 명령 프롬프트 (시작 메뉴 → `cmd`) |
| [서버] | VS Code 서버 터미널 (왼쪽 아래 `SSH: Anydoor-B200` 표시), 또는 `ssh` 로 접속한 창 |

- 명령은 코드 칸의 한 줄씩 입력
- 줄마다 정상 결과와 같은지 확인한 뒤 다음 줄로 넘어감
- [PC] 의 `tar`·`scp`·`ssh` 는 `C:\Windows\System32\…` 전체 경로로 실행
  - 이름만 쓰면 Git 이 설치한 같은 이름의 프로그램이 먼저 실행될 수 있음
  - 그 프로그램은 `C:\…` 를 다른 컴퓨터 이름으로 읽어 실패함
- 7단계 뒤로는 서버 터미널을 새로 열 때마다 `source /NHNHOME/workspace/env_anydoor.sh` 를 먼저 실행
