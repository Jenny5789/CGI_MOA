DB 관계도 (ERD)

테이블 6개와 외래키 12개로 구성되고, 선은 부모 테이블에서 자식 테이블로 향하며 부모 1건에 자식 여러 건이 연결됩니다.

표기

PK기본키
FK외래키 (→ 부모 테이블 · 삭제 규칙)
UK고유 키

관계선

1 : N 외래키가 NOT NULL
0..1 : N 외래키가 NULL 허용
user_id: 모든 테이블이 users 참조, 선 생략

삭제 규칙 (ON DELETE)

CASCADE 부모 삭제 시 자식 레코드도 삭제
SET NULL 부모 삭제 시 해당 컬럼만 NULL로 변경
NO ACTION 자식이 참조 중인 부모의 삭제 거부
업로드 사진 → 영역 추출 → 합성 작업 → 합성 결과 순으로 생성, 모든 테이블이 회원(users)에 연결
