## 2. 비기능 요구사항

| ID | 구분 | 요구사항 | 기준 |
|---|---|---|---|
| NFR-01 | 성능 | 합성 응답 시간 | 1건 약 25초, RTX 3080 10GB |
| NFR-02 | 자원 | GPU 메모리 10GB 환경 동작 | 16비트 가중치, 혼합 정밀도, 작업 후 GPU 메모리 반환 |
| NFR-03 | 보안 | 비밀번호 저장 | PBKDF2-SHA256 해시, 반복 600,000회 |
| NFR-04 | 보안 | 회원별 데이터 분리 | 본인 이미지·작업·결과만 접근 |
| NFR-05 | 보안 | 내부 서버 보호 | 외부 접속은 웹 화면 경로 하나, 모델 추론 서버 토큰 인증 |
| NFR-06 | 데이터 | 보관 기간 | 저장하지 않은 결과 24시간 뒤 삭제 |
| NFR-07 | 호환성 | 반응형 화면 | 데스크톱 1440px, 모바일 375px |
| NFR-08 | 운영 | 장애 복구 | 컨테이너 자동 재시작, 상태 확인 |
| NFR-09 | 운영 | 실행 환경 재현 | Docker 이미지, 패키지 버전 고정 |
