# MOA 기술 스택

버전은 `frontend/package.json`, `requirements.txt`, `model_server/requirements.txt`, Dockerfile 기준이다.

## 1. 언어

| 대상 | 기술 |
|---|---|
| 웹 서버, AI 모듈, 스크립트 | Python 3.10 |
| 웹 화면 | JavaScript, JSX |

## 2. 웹 화면

| 기술 | 버전 | 용도 |
|---|---|---|
| React | 19.1 | 화면 구성 |
| React Router | 6.30 | 페이지 이동: 홈, 합성하기, 마이페이지 |
| Vite | 6.3 | 개발 서버, 배포 빌드 |
| ESLint | 9.25 | 코드 검사, React Hooks 규칙 |
| Canvas API | - | 점 찍기, 마스크 편집, 확대·이동 |

- API 모드: `mock` 가짜 서버, `mixed`·`real` 실제 서버, `.env.local`의 `VITE_API_MODE`

## 3. 웹 서버·DB

## 4. AI·추론

| 기술 | 버전 | 용도 |

| PyTorch Lightning | 1.9.5 | AnyDoor 모델 구성·학습 |
| transformers, open_clip_torch, timm | 5.14.1, 3.3.0, 1.0.28 | AnyDoor 하위 모델 |
| OpenCV, Pillow, NumPy | 5.0, 12.3, 2.2.6 | 이미지 처리 |

### 4-1. 모델

| 모델 | 출처 | 용도 |
