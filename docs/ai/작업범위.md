# MOA 작업 범위

프로젝트 구현 범위, 팀원별 역할, AI 코딩 도구의 활용 범위를 정리한 문서다.

## 1. 구현 범위

### 1-1. 포함

| 영역 | 범위 |
|---|---|
| 합성 대상 | 상의 |
| 입력 | 상의 사진 1장, 인물 사진 1장, 클릭 기반 영역 지정과 마스크 편집 |
| AI 처리 | SAM2 이미지 분할, AnyDoor 이미지 합성, 초해상도, 원본 복원 후처리 |
| 추가 학습 | 의상 데이터 기반 AnyDoor 추가 학습과 서비스 가중치 선정 |
| 웹 서비스 | 홈, 합성하기, 마이페이지, 회원 계정, 사진첩, 고객센터 |
| 배포 | 운영 서버 웹 화면·웹 서버·DB 컨테이너, GPU 장비 모델 추론 서버 컨테이너 |

### 1-2. 미정

- 이미지 긴 변 길이 제한
- 결과 목록 분할 조회
- 결과 삭제 기능
- 출처: [docs/api.md](../api.md) 8. 미정 사항

## 2. 역할

| 역할 | 성명 | 범위 |
|---|---|---|
| 팀장 | 최이재 | 이미지 처리 파이프라인 구성, 합성 품질 개선, 백엔드 서버·DB 설계·구현, 작업 대기열·GPU 자원 관리, 회원 인증·파일 보호, 서비스 Docker 구성, 팀 문서 |
| 팀원 | 서지섭 | UI/UX 설계·프론트엔드 개발, 프론트엔드·서버 연동, 백엔드 기능·DB 스키마 확장, 합성 파이프라인 성능 개선, 의상 데이터 추가 학습, 모델 추론 서버 분리·Docker 배포 |
| 팀원 | 김기욱 | 합성 결과 평가 기준 수립, 테스트 지표 작성 |
| 팀원 | 정의형 | 이미지 분할 모델 비교 |

- 팀원별 수행 기록: [docs/작업일지.md](../작업일지.md) 최이재, [docs/작업일지_서지섭.md](../작업일지_서지섭.md) 서지섭

## 3. AI 활용 범위

### 3-1. 역할 구분

| 구분 | AI 코딩 도구 | 팀원 |
|---|---|---|
| 코드 | 초안 작성, 원인 추적, 리팩터링, 단위 시험 | 구조 설계, 검토, 화면 동작 확인, 채택 결정 |
| 실험 | 측정 스크립트 작성·실행, 수치·비교 그림 정리 | 실험 설계, 판정, 모델·가중치·옵션 결정 |
| 문서 | 설명서·작업일지·명세 초안 | 내용 검토·수정, 제출 |
| 배포 | Docker 구성 초안, 반영 절차 실행 | 반영 승인, 운영 확인 |

### 3-2. 팀원 결정 사항 예

| 결정 | 내용 |
|---|---|
| 합성 모델 | AnyDoor 기반 유지, 다른 합성 모델 도입 제외 |
| 서비스 가중치 | 추가 학습 가중치 `mix35000_fp16` 선정 |
| 배경 잔상 해결 | 경계 색 맞춤 방식 기각, 물체 기준 원본 복원 채택 |
| 합성 설정 | 4조합 비교 결과 기반 상의 경계 보정 켬, 영역 모양 유지 끔 고정 |
| 배포 구성 | 모델 추론만 GPU 장비 컨테이너로 분리 |

### 3-3. 제한

- 커밋·푸시·운영 서버 반영은 팀원 요청 시에만
- 운영 DB에 시험 데이터 입력 금지
- 실행 중 프로그램 임의 종료 금지
- 상세: [CLAUDE.md](../../CLAUDE.md) 2. 작업 원칙
