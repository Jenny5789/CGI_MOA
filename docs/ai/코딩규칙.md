# MOA 코딩 규칙

저장소 코드에 적용된 규칙이다. 새 코드도 같은 규칙을 따른다.

## 1. 공통

- 주석·문서·화면 문구는 한국어, 식별자는 영어
- 주석은 동작보다 이유 중심: 결정 날짜, 근거 실험, 바꾼 이유
- 파일 첫머리에 역할과 처리 방식 요약
- API 관련 코드에 명세 장 번호 표기: `명세 5-1`
- 미사용 코드는 주석으로 남기지 않고 삭제, 삭제 이유는 작업일지에 기록
- 설정값은 상수 또는 환경 변수로 분리, 비밀값은 `.env`에만

## 2. 웹 서버 · Python

| 항목 | 규칙 |
|---|---|
| 구조 | `backend/routers/` 기능별 라우터, `backend/config.py` 상수, `backend/db.py` 테이블 정의 |
| 오류 | `ApiError(상태 코드, 코드, 메시지)`로 발생, 응답은 `{ "error": { "code", "message" } }` |
| 오류 코드 | 대문자 스네이크 표기: `INVALID_IMAGE`, `MODEL_LOADING` |
| 오류 메시지 | 화면에 그대로 표시되는 안내 문장 |
| 인증 | `Depends(current_user)`, 다른 회원 데이터는 404 |
| DB | SQLAlchemy ORM, SQLite·MySQL 공용 코드 |
| 모델 호출 | `backend/model_client.py` 경유, `MODEL_SERVER_URL` 유무로 원격·직접 실행 선택 |
| 긴 작업 | 작업 번호 즉시 응답, 대기열 스레드 하나가 순서대로 처리 |
| 시험 | `scripts/` 단위 테스트, API 시험은 임시 SQLite |

## 3. AI 모듈

- 위치: `features/object_extraction/` 이미지 분할, `features/composition/` 합성·후처리
- AnyDoor 원본 파일은 수정하지 않음, 필요한 변경은 불러온 뒤 적용
- 같은 입력·같은 seed로 변경 전후 결과 비교 후 채택
- GPU 메모리: 16비트 가중치, 혼합 정밀도, 작업 후 메모리 반환
- 측정 지표는 실험 기록에 남김: 시간, GPU 메모리 최고값, IoU, 색 차이

## 4. 웹 화면 · React

| 항목 | 규칙 |
|---|---|
| 구조 | `pages/` 페이지, `studio/` 합성하기 부품, `mypage/` 마이페이지, `auth/` 로그인, `api/` 서버 요청, `utils/` 공용 함수 |
| 컴포넌트 | 함수 컴포넌트와 Hooks |
| 서버 요청 | API 호출은 `src/api/`의 함수만 사용, 화면 코드에서 `fetch` 직접 호출 금지. 결과 이미지 내려받기 `utils/download.js`만 예외 |
| API 모드 | `mock`·`mixed`·`real`, 새 API는 `mock.js`에 가짜 응답 함께 추가 |
| 스타일 | 영역별 CSS 파일, 클래스 접두어로 구분: `sg-` 합성하기, `as-` 마이페이지 |
| 문구 | `~입니다` 통일, 보조 설명·장식 기호 금지, 예시 글은 placeholder |
| 검사 | `npm run lint`, `npm run build` 통과 후 브라우저 확인 |

## 5. Git

| 항목 | 규칙 |
|---|---|
| 브랜치 | `main` 팀 공용, `dev-sjs`·`dev-cej` 개인 작업 |
| 병합 | 개인 브랜치 → `main` PR |
| 작업 시작 | `git pull origin main` |
| 커밋 메시지 | `종류: 한국어 요약`, 본문에 이유 |
| 커밋 종류 | `feat`, `fix`, `perf`, `refactor`, `docs`, `revert`, `chore` |
| 제외 | 모델 가중치 `checkpoints/`, 사용자 데이터 `storage/`, `.env`, 가상환경, 데이터셋 |
