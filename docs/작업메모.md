## 3. 서버 팀원에게 전달하거나 물어볼 것

- [ ] 시험용 계정: 가짜 서버는 `test` / `test`인데, 비밀번호 규칙(8자 이상, 숫자 포함)에 맞지 않는다. 진짜 서버 시험 계정은 규칙에 맞게 정해 달라고 하기.
- [ ] 사진 주소(`/api/files`) 보호 방식 (명세 7장, 미정). 서버가 이 주소를 만들기 전에 정해야 함.
- [ ] 진짜 서버가 일부라도 켜지면 언제, 어떤 주소에서 쓸 수 있는지.
- [ ] 위 2번 "임시로 정한 것" 확인.

## 4. 진짜 서버에 붙였을 때 다시 확인할 것

가짜 서버에서는 되지만 진짜 서버에서는 다를 수 있는 것.

- [ ] 사진첩 사진이 보이는지. 가짜는 `/assets/...`, 진짜는 `/api/files/...` 주소 (3번의 사진 주소 보호 방식과 연결됨)
- [ ] 응답이 느릴 때 "불러오는 중…"이 나오는지
- [ ] 로그인 만료(401) 때 로그인 창이 "로그인이 만료되었습니다" 문구로 뜨는지
- [ ] 날짜 거르기가 한국 시간 기준으로 맞는지 (밤 9시 이후 만든 결과로 확인)
- [ ] 오류 응답이 명세 형식 `{ error: { code, message } }`인지. 아니면 화면에 "요청을 처리하지 못했습니다"만 나옴
- [ ] 실제 배포 때 `/api` 요청을 서버로 넘기는 설정 (지금 설정은 `npm run dev` 개발 서버에서만 동작)

## 5. 화면에 보이는 것을 바꾼 경우

화면 담당자에게 알려야 한다.

- 마이페이지 "최근 작업" 탭 설명에 "저장하지 않은 결과는 3일 뒤 사라집니다"를 덧붙임 (명세 5-3)
- 마이페이지 로그아웃 버튼: "준비 중" 안내에서 실제 로그아웃으로 바뀜. 로그아웃 상태에서는 숨김
- 마이페이지를 로그아웃 상태로 열면 사진첩 자리에 "로그인하면 사진첩을 볼 수 있습니다", 프로필은 비어 있음
- 사진첩 목록을 받는 동안 "불러오는 중…", 실패하면 서버가 준 안내 문구가 나옴
- 로그인 버튼: 기다리는 동안 "로그인 중…"으로 바뀌고 눌리지 않음
- 로그인이 만료되면 로그인 창이 "로그인이 만료되었습니다. 다시 로그인해 주세요." 문구로 열림
- 합성하기 "내 작업 기록": 고정 예시 5장 대신 사진첩 "전체"와 같은 목록이 나옴. 목록을 못 받으면 아래에 안내 문구가 잠깐 뜸

## 6. 확인한 방법

진짜 서버에 붙였을 때 같은 순서로 다시 확인한다. `npm run dev` 뒤 브라우저에서.

**로그인 / 로그아웃**
1. 틀린 비밀번호 → "아이디 또는 비밀번호가 올바르지 않습니다", 버튼이 잠깐 "로그인 중…"
2. 맞는 비밀번호 → 로그인, 위쪽 메뉴가 "로그아웃"으로 바뀜
3. 로그아웃 → 위쪽 메뉴가 "로그인"으로 바뀌고 로그인 창은 뜨지 않음
4. 로그인 만료: 브라우저 개발자 도구에서 `localStorage`의 `moa_token`을 아무 값으로 바꾼 뒤 마이페이지 새로고침 → 로그인 창이 만료 문구로 뜸

**마이페이지 사진첩** (가짜 서버 기준 숫자)
1. 로그아웃 상태로 `/mypage` → "로그인하면 사진첩을 볼 수 있습니다"
2. 로그인 → 사진 20장, 탭 숫자 전체 20 / 최근 작업 6 / 좋아요 6, 프로필 이름과 이메일
3. 최근 작업 탭에서 "저장" → "사진첩에 저장했습니다", 숫자 21 / 5 / 6
4. 좋아요 탭에서 하트 끄기 → 좋아요 숫자 5
5. 오래된순 → 첫 사진이 2026.08.25
6. 날짜 2026-09-20 → 2장, 사진 없는 날짜 → "표시할 이미지가 없습니다"
7. 로그아웃 버튼 → 사진첩과 프로필이 비워짐

**합성하기 "내 작업 기록"**
1. 로그인 뒤 합성하기 → 오른쪽 칸에 20장, 맨 위 2026.09.20 14:32, 맨 아래 2026.08.25 10:08 (사진첩 "전체"와 같은 목록)
2. 사진 하나 누르기 → 가운데에 "저장된 결과"로 크게 보임
3. 마이페이지에서 최근 작업 하나를 저장한 뒤 합성하기로 이동 → 그 사진이 목록에 들어 있음 (새로고침하면 가짜 서버가 처음 상태로 돌아가므로 메뉴로 이동할 것)

가짜 서버 데이터는 메모리에만 있어서 새로고침하면 처음 숫자로 돌아간다.
