- 기록 원칙: 서버 주소·계정·키, 개인 경로 미기재. VITON-HD 사진과 사진 파일 이름 미기재
- 용어
  - 유형 B: AnyDoor 공식 가중치 합성에서 입고 있던 상의 자리에 긴소매·늘어진 천이 남는 사례 5장, seed 3개로 확인
  - 95쌍 비교: VITON-HD 평가 95쌍의 이음새 강도·비편집 영역 밝기 측정과 육안 판정
  - 가중치 이름: `aug10000` 1안 10,000스텝, `aug50000` 1안 50,000스텝, `mix35000` 3안 35,000스텝
