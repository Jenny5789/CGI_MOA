# 로그인 세션 연장 정책

## 1. 개요

- 로그인 유지 시간을 제한하고, 만료 전 사용자 선택으로 연장
- 관련 API: [api.md 2-5. 로그인 시간 연장](api.md#2-5-로그인-시간-연장-추가-제안)

## 2. 유효 시간

| 항목 | 내용 |
|---|---|
| 유효 시간 | 로그인 시각부터 3시간 (사용 중에도 자동 연장 없음) |
| 연장 시 | 연장한 시각부터 다시 3시간 |
| 연장 횟수 | 제한 없음 |

## 3. 연장 안내

| 시점 | 안내 문구 (예시) | 선택지 |
|---|---|---|
| 만료 30분 전 | "30분 뒤 자동 로그아웃됩니다. 연장할까요?" | 연장, 아니요 |
| 만료 10분 전 | "10분 뒤 자동 로그아웃됩니다. 연장할까요?" | 연장, 아니요 |
| 만료 | 로그아웃 후 로그인 창 표시 | - |

- 처리 규칙
  1. 30분 전 "연장" 선택 → 10분 전 재안내 없음
  2. 30분 전 "아니요" 또는 무응답 → 10분 전 재안내
  3. 10분 전에도 "아니요" 또는 무응답 → 만료 시 로그아웃

```
로그인 3:00 ─── 5:30 안내
                  ├─ 연장 → 만료 8:30
                  └─ 아니요 ─── 5:50 재안내
                                  ├─ 연장 → 만료 8:50
                                  └─ 아니요 → 6:00 로그아웃
```

## 4. 프론트엔드 함수 (`frontend/src/api/auth.js`)

| 함수 | 기능 | 반환 |
|---|---|---|
| `getExpiresAt()` | 저장된 만료 시각 조회 | `Date`, 로그인 전 `null` |
| `extendLogin()` | 백엔드에 연장 요청, 새 만료 시각 저장 | 새 만료 시각 `Date` |

- 만료 시각은 브라우저 `localStorage`에 저장 (새로고침 후에도 유지)
- 만료 후 `extendLogin()` 호출 시 401 → 로그아웃 후 로그인 창 표시
- 백엔드 없이 프론트엔드만 실행할 때(`VITE_API_MODE=mock`)도 같은 함수로 화면 개발 가능
