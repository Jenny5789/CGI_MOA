# 로그인 시간 연장

- 명세 외 추가 (2026-10-15, 팀 합의 필요)
- 서버·요청 함수 준비됨 → 화면에 안내 창만 붙이면 됨

## 규칙

- 유효 시간: 로그인 시각부터 3시간 (쓰는 중에도 자동 연장 없음)
- 연장: 연장한 시각부터 다시 3시간, 횟수 제한 없음

## 안내 창

| 때 | 안내 (예시) | 버튼 |
|---|---|---|
| 만료 30분 전 | "30분 뒤 자동 로그아웃됩니다. 연장할까요?" | [연장] [아니요] |
| 만료 10분 전 | "10분 뒤 자동 로그아웃됩니다. 연장할까요?" | [연장] [아니요] |
| 만료 | 로그아웃 + 로그인 창 | - |

- 30분 전에 [연장] → 10분 전 재확인 없음
- 30분 전에 [아니요]·무응답 → 10분 전 재확인
- 10분 전에도 [아니요]·무응답 → 만료 시 로그아웃

```
로그인 3:00 ─── 5:30 확인
                  ├─ [연장] → 만료 8:30
                  └─ [아니요] ─── 5:50 재확인
                                    ├─ [연장] → 만료 8:50
                                    └─ [아니요] → 6:00 로그아웃
```

## 함수 (`frontend/src/api/auth.js`)

| 함수 | 하는 일 |
|---|---|
| `getExpiresAt()` | 만료 시각(`Date`), 로그인 전 `null` |
| `extendLogin()` | 연장 요청 → 새 만료 시각(`Date`), 저장 자동 |

- 만료 시각은 `localStorage`에 저장 (새로고침해도 유지)
- 만료 후 `extendLogin()` → 401 → 로그아웃 + 로그인 창
- `mock` 모드에서도 동작

## 서버

- 로그인·회원가입 응답에 `expires_at` (한국 시간, 예 `2026-10-15T18:20:00+09:00`)
- `POST /api/auth/extend` (로그인 필요, 보내는 값 없음) → `{ "expires_at": "..." }`
- 만료된 토큰은 401
