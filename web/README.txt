MOA 웹 화면 (web/) 안내

1. 지금 상태
- 화면의 기본 틀만 만든 시안입니다. 화면 구성과 사용 흐름(사진 올리기, 점 찍기, 칠하기, 합성 중, 결과, 저장)을 보여 주는 용도입니다.
- 실제 AI 기능(SAM2 추출, AnyDoor 합성)은 연결되어 있지 않습니다. 서버나 DB와 주고받는 코드도 없습니다.
- 브라우저에서 index-light.html을 열면 바로 볼 수 있습니다.

2. 파일
- index-light.html : 홈
- studio2.html     : 합성하기 화면 (studio-guide.js, studio-panels.js, studio-guide.css)
- mypage.html      : 마이페이지(사진첩)
- auth-modal.js    : 로그인 팝업
- app-shell, landing-light, topnav : 공통 화면 요소
- assets/          : 로고, 홈 배경, 샘플, 갤러리 이미지 (갤러리 이미지는 모두 AI로 만든 이미지)

3. 지금은 흉내만 내는 부분 (기능 연동 시 바꿔야 할 곳)
- 3단계 상의 추출 (studio-guide.js, confirm-3 부분)
  지금: 찍은 점마다 동그라미 모양으로 잘라낼 뿐이고 SAM2를 쓰지 않습니다.
  바꿀 것: 사진과 점 좌표를 서버로 보내고, SAM2가 만든 마스크를 받아서 쓰도록 수정.
- 4단계 합성 (studio-guide.js, compose 함수와 confirm-4 부분)
  지금: 3.2초 기다린 뒤 잘라낸 상의를 칠한 영역에 그대로 붙입니다. AI 합성이 아닙니다.
  바꿀 것: 사진, 마스크, 칠한 영역을 서버로 보내고 AnyDoor 결과 이미지를 받아 결과 화면에 표시하도록 수정.
- 결과 저장과 작업 기록 (studio2.html 오른쪽 패널, mypage.html)
  지금: 페이지 안의 임시 목록이라 새로고침하면 사라집니다. 마이페이지 목록은 assets/gallery의 예시 이미지를 고정으로 넣어 둔 것입니다(mypage.html의 items).
  바꿀 것: 합성 결과 이미지를 서버에 저장하고 DB에 기록한 뒤, 그 목록을 불러와 보여 주도록 수정. 예시 이미지 대신 실제 결과 이미지가 들어가야 합니다.
- 로그인 (auth-modal.js)
  지금: 시연용으로 아이디 test, 비밀번호 test가 코드에 고정되어 있고 로그인 상태는 브라우저에만 저장됩니다.
  바꿀 것: 실제 회원 DB와 서버 인증으로 교체.
- 홈과 갤러리 이미지 (index-light.html, studio-guide.js)
  지금: assets 폴더의 예시 이미지를 고정 경로로 씁니다.
  바꿀 것: 실제 합성 결과로 바꾸려면 이미지 파일과 경로를 함께 수정.

4. 정리
기능을 연결하려면 위 부분의 코드와 이미지 파일을 모두 수정해야 합니다. 특히 결과가 나오는 곳에는 실제 합성 결과 이미지가 들어가야 하고, 저장과 목록은 DB와 연결해야 합니다.
