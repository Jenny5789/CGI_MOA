1단계 · 객체 이미지 선택

예시
사진을 끌어다 놓으세요 또는 우측 상단의 업로드 버튼으로 선택하세요
객체 이미지란?

입혀볼 상의가 담긴 사진입니다. 상의가 또렷하게 보이는 사진일수록 결과가 자연스럽습니다. 이 사진에서 상의만 추출하여 다음 단계에서 사용합니다.

2단계 · 배경 이미지 선택

예시
사진을 끌어다 놓으세요 또는 우측 상단의 업로드 버튼으로 선택하세요
배경 이미지란?

상의를 입어볼 인물이 나온 사진입니다. 상반신이 잘 보이는 사진을 선택하세요. 상의만 바뀌고 나머지는 그대로 유지됩니다.

3단계 · 객체 추출 (점 찍기)

사용 방법

AI(SAM)가 상의 영역을 찾을 수 있도록 상의 위를 클릭하여 점을 찍으세요. 왼쪽 클릭은 “포함”, 오른쪽 클릭은 “제외”입니다. 점을 다시 클릭하면 삭제됩니다.

1단계에서 객체 이미지를 먼저 선택하세요.

4단계 · 합성할 영역 지정

사용 방법

상의가 합성될 영역을 지정합니다. 점으로 몸통을 클릭하면 영역이 잡히고, 브러시로 부족한 부분을 덧칠하거나 지우개로 삭제할 수 있습니다. 확인을 누르면 바로 합성이 시작됩니다.

2단계에서 배경 이미지를 먼저 선택하세요.
