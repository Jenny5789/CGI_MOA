# 사람 추출 모델 비교

- 비교 시작일: 2026-09-22
- 최근 비교일: 2026-09-23
- 실험 단계: 사람 추출 모델 비교
- 비교 모델: BiRefNet / SAM2


## 1. 비교 목적

MOA의 사람 이미지 추출 기능에 사용할 방법을 검토하기 위해
BiRefNet과 SAM2의 사람 Mask 결과를 비교한다.

현재 단계에서는 Ground Truth Mask를 사용한 정량 평가가 아니라
실제 생성된 Mask를 육안으로 비교한다.

한 장의 결과만으로 모델 전체의 성능 우열을 결정하지 않고,
이미지를 추가하면서 비교 결과를 누적한다.

현재까지 비교한 이미지는 다음과 같다.

1. `Girl.jpg`
2. `Standing_man.jpg`
3. `Bent_man.jpg`


# 비교 이미지 01 — Girl


## 2. 입력 조건

입력 이미지:

- 파일명: `Girl.jpg`
- 이미지 크기: 975 × 1463

입력 위치:

`experiments/object_extraction/001_person_extraction/inputs/Girl.jpg`

BiRefNet과 SAM2 모두 동일한 `Girl.jpg`를 사용하였다.

비교 결과:

### BiRefNet

`Girl_BiRefNet_mask_00001_.png`

### SAM2

`Girl_SAM2_point2_mask_00001_.png`

SAM2는 Positive Point 1개, 2개, 3개를 테스트하였다.

1-Point에서는 사람 전체가 아닌 의복 중심 영역이 선택되었고,
2-Point에서는 사람 전체에 가까운 Mask가 생성되었다.

3-Point 결과는 2-Point 결과와 육안상 전체적인 형태가 유사하였기 때문에
이번 모델 간 비교에서는 2-Point 결과를 사용하였다.


## 3. Girl — 결과 확인

### BiRefNet

육안으로 확인된 내용:

- 사람의 전체적인 실루엣이 Mask에 포함되었다.
- SAM2 2-Point 결과에서 보였던 상체 내부의 작은 누락이 상대적으로 적게 보였다.
- 머리카락과 의류 끝부분처럼 가느다란 영역도 일부 Mask에 표현되었다.
- 오른쪽 하단에 사람 이외의 주변 구조물로 보이는 영역이 함께 포함되었다.
- 다리 주변에도 가느다란 영역이 함께 Mask에 포함된 부분이 확인되었다.
- 팔과 몸 사이처럼 배경이 보이는 일부 영역은 검은색으로 분리되어 있다.

### SAM2 2-Point

육안으로 확인된 내용:

- 사람 전체 영역은 대체로 Mask에 포함되었다.
- 상체와 팔 주변에 작은 내부 누락이 여러 곳 보였다.
- 특히 왼쪽 팔과 상체 주변의 Mask가 불규칙하게 나타났다.
- 오른쪽 하단에 사람 이외의 주변 구조물로 보이는 영역이 일부 포함되었다.
- 사람 내부 영역이 완전히 연속적으로 채워지지 않은 부분이 확인되었다.


## 4. Girl — 비교

| 비교 항목 | BiRefNet | SAM2 2-Point |
|---|---|---|
| 사람 전체 영역 | 전체적인 실루엣 포함 | 전체 영역 대체로 포함 |
| Mask 내부 누락 | 상대적으로 적게 관찰됨 | 상체·팔 주변에서 여러 곳 관찰됨 |
| 가느다란 영역 | 머리카락·의류 끝부분 일부 표현 | 일부 영역 표현 |
| 주변 영역 오검출 | 관찰됨 | 관찰됨 |
| 사용자 Prompt | 없음 | Positive Point 2개 |
| 입력 조건 | 동일 이미지 | 동일 이미지 |

`Girl.jpg`에서는 BiRefNet 결과가 SAM2 2-Point 결과보다
사람 내부 영역이 상대적으로 연속적으로 채워진 형태로 관찰되었다.

반면 두 방법 모두 사람 주변의 일부 영역이
Mask에 포함되는 현상이 확인되었다.

Ground Truth가 없으므로 실제 경계 정확도의 우열은 판단하지 않는다.


# 비교 이미지 02 — StandingMan


## 5. 입력 조건

### BiRefNet

입력:

`Standing_man.jpg`

이미지 크기:

3000 × 5332

비교 결과:

`Standingman_BiRefNet_mask_00001_.png`

### SAM2

원본 이미지:

`Standing_man.jpg`

SAM2 실험 입력:

`Standingman_2305x4096.jpg`

이미지 크기:

2305 × 4096

비교 결과:

`Standingman_SAM2_point2_mask_00001_.png`

SAM2는 Positive Point 1개, 2개, 3개를 테스트하였다.

1-Point에서는 상체 중심 영역이 선택되었고,
2-Point에서는 사람 전체 영역이 생성되었다.

3-Point 결과는 2-Point와 전체적인 형태가 육안상 유사하였기 때문에
이번 모델 간 비교에서는 2-Point 결과를 사용하였다.


## 6. StandingMan — 비교 조건의 제한

BiRefNet은 원본 3000 × 5332 이미지를 사용하였다.

SAM2는 현재 사용한 Points Editor의 height 최대값 4096 제한으로 인해
가로세로 비율을 유지하여 축소한 2305 × 4096 이미지를 사용하였다.

따라서 동일한 원본 장면에서 생성한 결과이지만
두 모델에 실제로 입력된 이미지의 픽셀 해상도는 동일하지 않다.

이 때문에 StandingMan 결과는 두 모델의 Mask 형태를 관찰하는
참고 비교로 사용하며,
통제된 동일 입력 조건의 직접 비교로 취급하지 않는다.


## 7. StandingMan — 결과 확인

### BiRefNet

육안으로 확인된 내용:

- 머리부터 신발까지 사람 전체가 Mask에 포함되었다.
- 사람 영역이 하나의 연속된 Mask로 나타났다.
- 두 다리 사이의 배경이 분리되어 있다.
- 현재 화면에서는 눈에 띄는 큰 내부 누락이 거의 보이지 않았다.
- 현재 육안 확인 범위에서는 사람과 떨어진 큰 배경 영역이 포함된 모습은 보이지 않았다.

### SAM2 2-Point

육안으로 확인된 내용:

- 머리부터 신발까지 사람 전체가 Mask에 포함되었다.
- 몸통과 다리가 연결된 영역으로 나타났다.
- 두 다리 사이의 배경이 대부분 분리되었다.
- 목 부분에 작은 내부 누락이 관찰되었다.
- 신발 주변에 작은 불규칙 영역이 관찰되었다.
- 현재 육안 확인 범위에서는 큰 주변 구조물이 Mask에 포함된 모습은 보이지 않았다.


## 8. StandingMan — 비교

| 비교 항목 | BiRefNet | SAM2 2-Point |
|---|---|---|
| 사람 전체 영역 | 포함 | 포함 |
| 전체 실루엣 | 사람 전체 형태 확인 | 사람 전체 형태 확인 |
| 내부 누락 | 현재 육안상 큰 누락 거의 없음 | 목 부분에 작은 누락 관찰 |
| 신발 주변 | 사람 영역 포함 | 작은 불규칙 영역 관찰 |
| 큰 주변 영역 포함 | 현재 육안상 확인되지 않음 | 현재 육안상 확인되지 않음 |
| 사용자 Prompt | 없음 | Positive Point 2개 |
| 실험 입력 크기 | 3000 × 5332 | 2305 × 4096 |

두 모델 모두 머리부터 신발까지 사람 전체 영역을 추출하였다.

BiRefNet 결과에서는 현재 육안 확인 범위에서
상대적으로 연속적인 사람 Mask가 관찰되었다.

SAM2 2-Point 결과에서는 목 부분의 작은 내부 누락과
신발 주변의 작은 불규칙 영역이 관찰되었다.

다만 Ground Truth가 없고 실제 입력 해상도도 다르기 때문에
이 결과만으로 두 모델의 성능 우열을 판단하지 않는다.


# 비교 이미지 03 — BentMan


## 9. 입력 조건

- 비교일: 2026-09-23
- 원본 이미지: `Bent_man.jpg`
- 원본 이미지 크기: 3536 × 5304

Points Editor의 최대 height 4096 제한을 고려하여
가로세로 비율을 유지한 공통 실험 이미지를 생성하였다.

공통 실험 이미지:

- 파일명: `Bent_man_2791x4096.jpg`
- 이미지 크기: 2791 × 4096

입력 위치:

`experiments/object_extraction/001_person_extraction/inputs/Bent_man_2791x4096.jpg`

이번 비교에서는 BiRefNet과 SAM2 모두
동일한 `Bent_man_2791x4096.jpg`를 사용하였다.

따라서 StandingMan 비교에서 존재했던
모델 간 입력 이미지 해상도 차이를 제거하였다.


## 10. 비교 결과 선정

### BiRefNet

비교 결과:

`Bent_man_BiRefNet_mask_00001_.png`

별도의 Point Prompt는 사용하지 않았다.

### SAM2

SAM2는 동일한 입력 이미지에서
Positive Point 1개, 2개, 3개를 테스트하였다.

1-Point:

- 몸통 및 상의 주변 영역이 주로 선택되었다.
- 사람 전체 영역은 생성되지 않았다.

2-Point:

- 머리부터 신발까지 사람 전체에 가까운 Mask가 생성되었다.

3-Point:

- 사람 전체 영역이 생성되었다.
- 2-Point 결과와 전체적인 형태가 육안상 매우 유사하였다.

따라서 이번 모델 간 비교에서는 다음 결과를 사용하였다.

`Bent_man_SAM2_point2_mask_00001_.png`


## 11. BentMan — BiRefNet 결과 확인

육안으로 확인된 내용:

- 크게 허리를 숙인 자세에서도 머리부터 신발까지 사람 전체가 Mask에 포함되었다.
- 머리, 몸통, 뒤로 뻗은 팔, 하체와 신발이 연결된 사람 영역으로 나타났다.
- Mask 내부에서 눈에 띄는 큰 누락 영역은 관찰되지 않았다.
- 머리카락의 전체적인 외곽 형태가 Mask에 포함되었다.
- 현재 육안 확인 범위에서는 사람과 떨어진 큰 배경 영역이 포함된 모습은 보이지 않았다.


## 12. BentMan — SAM2 2-Point 결과 확인

육안으로 확인된 내용:

- 머리부터 신발까지 사람 전체 형태가 Mask에 포함되었다.
- 뒤로 뻗은 양팔도 사람 영역에 포함되었다.
- 몸통, 팔과 하체가 연결된 영역으로 나타났다.
- 몸통 및 허리 주변에 작은 내부 누락 영역이 관찰되었다.
- 손 및 손목 주변에도 일부 불규칙한 영역이 관찰되었다.
- 신발 주변에 작은 불규칙 영역이 관찰되었다.

# 세 이미지 누적 비교


## 14. SAM2 Point Prompt 누적 관찰

현재까지 테스트한 세 이미지에서
SAM2의 Point 개수에 따른 결과는 다음과 같이 관찰되었다.

| 이미지 | 1-Point | 2-Point | 3-Point |
|---|---|---|---|
| Girl | 의복 중심 | 사람 전체에 가까운 영역 | 2-Point와 전체 형태 유사 |
| StandingMan | 상체 중심 | 사람 전체 영역 | 2-Point와 전체 형태 유사 |
| BentMan | 몸통·팔 일부 | 사람 전체에 가까운 영역 | 2-Point와 전체 형태 유사 |

현재 테스트한 세 이미지에서는
Positive Point 1개만 사용했을 때 사람 전체 영역이 생성되지 않았다.

Positive Point 2개를 사용했을 때는
세 이미지 모두 사람 전체에 가까운 영역으로 Mask가 확장되었다.

Positive Point 3개를 사용했을 때는
세 이미지 모두 2-Point 결과 대비 전체적인 Mask 형태의 큰 변화가
육안상 관찰되지 않았다.

이 결과는 현재 테스트한 세 이미지에서 반복적으로 관찰된 현상이다.

따라서 이를
`SAM2는 항상 2개의 Point가 가장 좋다`
또는
`SAM2는 사람 추출에 2개의 Point가 필요하다`
라고 일반화하지 않는다.


## 15. BiRefNet 누적 관찰

현재까지 테스트한 세 이미지에서
BiRefNet은 별도의 Point Prompt 없이 사람 Mask를 생성하였다.

- `Girl.jpg`
- `Standing_man.jpg`
- `Bent_man_2791x4096.jpg`

세 이미지 모두에서 사람 전체 영역에 해당하는 Mask가 생성되었다.

현재 육안 확인 범위에서는
세 이미지 모두 사람의 큰 실루엣을 확인할 수 있었다.

다만 세 장의 테스트 결과만으로
다른 모든 사람 이미지에서도 동일한 결과가 나온다고 일반화하지 않는다.


## 16. 현재까지 확인된 사용 방식의 차이

현재 테스트 과정에서 확인된 가장 명확한 차이는
두 모델의 입력 방식이다.

### BiRefNet

현재 테스트에서는:

`사람 이미지`

→ `BiRefNet`

→ `사람 Mask`

형태로 사용하였다.

별도의 사용자 Point 입력을 사용하지 않았다.

### SAM2

현재 테스트에서는:

`사람 이미지`

+ `Positive Point`

→ `SAM2`

→ `사람 Mask`

형태로 사용하였다.

현재 테스트한 세 이미지에서는
사람 전체 영역을 얻기 위해 1-Point 결과에서
추가 Point 입력이 필요하였다.

이 차이는 향후 MOA 서비스에서
사람 추출 기능의 사용자 조작 방식과도 관련될 수 있다.

다만 현재 단계에서는 이를 근거로
최종 모델을 선정하지 않는다.


## 17. 현재 단계에서 판단하지 않은 내용

현재 비교에서는 Ground Truth Mask를 사용하지 않았다.

따라서 다음 항목은 아직 판단하지 않는다.

- BiRefNet과 SAM2의 전체적인 성능 우열
- 사람 이미지 전반에 대한 일반적인 정확도
- IoU
- Dice
- 정량적인 경계 정확도
- 평균 추론 시간 비교
- Peak VRAM 비교
- 처리 속도 우열
- 모든 이미지에서 SAM2 2-Point가 최적이라는 결론
- 최종 MOA 사람 추출 모델 선정

StandingMan 비교에서는 모델별 입력 이미지의 해상도도 달랐다.

BentMan부터 동일한 크기의 입력 이미지를 사용하여
비교 조건을 통제하였다.
